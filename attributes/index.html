    Attributes

    Attribute Arguments

    • <argument> - Required Argument
    • {optional} - Optional Argument
    Tool Attribute Description Applies Usage
    AUTO_COLLECT automatically teleports items into the player's inventory GLOBAL AUTO_COLLECT
    AUTO_SELL automatically sells item in tool inventory(requires vault) GLOBAL AUTO_SELL
    DROP_BOOST increases the amount of items dropped GLOBAL AUTO_COLLECT
    DROP_ITEM drops an item when activated GLOBAL DROP_ITEM
    EXPERIENCE_MULTIPLIER makes the tool gain experience faster GLOBAL EXPERIENCE_MULTIPLIER:<multiplier>
    POTION_EFFECT gives the player a potion effect while holding the item GLOBAL UNBREAKABLE:<true/false>
    UNBREAKABLE prevents the item from losing durability GLOBAL UNBREAKABLE:<true/false>
    REPLANT_SAPLING replants saplings when the bottom-most block of a tree is broken AXE REPLANT_SAPLING:{chance}
    TIMBER breaks all logs instantly AXE TIMBER:<max-logs>:<destoy-leaves>:{chance}
    AREA_HARVEST Harvests crops in an area HOE AREA_HARVEST:<radius>:<chance>
    BOUNTIFUL_HARVEST generates extra crops HOE BOUNTIFUL_HARVEST:<multiplier>:<chance>
    CHAIN_HARVEST destroys crops in a snake like manner HOE CHAIN_HARVEST:<max_blocks>:<chance>
    CROP_FORTUNE increases the amount of crops dropped by crops HOE CROP_FORTUNE:<amount>
    FERTILE_TOUCH upon harvesting a crop, nearby crops have a chance to advance in growth HOE FERITLE_TOUCH:<power>:<radius>:<max_crops>:<chance>
    HARVESTER harvests any crop type instantly HOE HARVESTER:<true/false>
    INSTANT_REGROWTH chance to instantly regrow a broken crop HOE INSTANT_REGROWTH:<chance>
    REJUVENATING_PULSE creates a circle that grows nearby crops when activated HOE REJUVINATING_PULSE:<power>:<radius>:<duration>:<chance>:<cooldown>
    REPLANT_SEEDS Automatically replant seeds if they are in the player's inventory HOE REPLANT_SEEDS:<chance>
    REQUIRE_MATURE when true, allows a harvester tool to only break fully grown crops HOE REQUIRE_MATURE:<true/false>
    BLACKSMITH restores durability while mining PICKAXE PLACEHOLDER
    BLASTING destroys all blocks in a radius PICKAXE BLASTING:<radius>:{radius}
    DESTROY_ORES when true, the blasting tools will break ores PICKAXE PLACEHOLDER
    FORGE restores durability to all items in inventory PICKAXE PLACEHOLDER
    GEOLOGIST chance to discover bonus minerals when mining stone PICKAXE PLACEHOLDER
    SMELT_ORES automatically smelts ores when broken PICKAXE PLACEHOLDER
    VEIN_MINER mines all ores in a vein PICKAXE PLACEHOLDER
